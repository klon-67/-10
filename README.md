# 💣 Bomb Clicker

**Bomb Clicker** — це весела гра на Python, створена за допомогою бібліотеки **Tkinter**.
Твоє завдання — не дати бомбі вибухнути та набрати якомога більше очок! 🎮

## 🎯 Мета гри

На початку гри запобіжник бомби має **100**.

Бомба поступово втрачає заряд. Тобі потрібно швидко натискати на кнопку та збільшувати значення запобіжника.

Якщо значення досягне **0** — бомба вибухне! 💥

## 🕹️ Як грати

1. Запусти програму.
2. Натисни **Enter** або кнопку **START**.
3. Натискай **💣 CLICK!**, щоб збільшувати запобіжник.
4. Намагайся набрати якомога більше очок.
5. Не дай запобіжнику опуститися до `0`.
6. Після вибуху натисни кнопку ще раз, щоб почати нову гру.

* 🖱️ Керування за допомогою кнопки

* 🔥 Комбо за швидкі кліки

## 📈 Рівні

За кожні **10 очок** гравець переходить на новий рівень.

Чим вищий рівень, тим швидше зменшується запобіжник.

Тому гра поступово стає складнішою! 🔥

## 🔥 Комбо

За кожні **10 кліків** спрацьовує комбо.

Гравець отримує:

* `+10` до запобіжника
* `+5` очок

Це допомагає врятувати бомбу в небезпечний момент.

## 🎲 Випадковий бонус

Кожен клік додає до запобіжника випадкове значення від:

```text
+2 до +6
```

Тому кожна гра може проходити по-різному.

## 🏆 Рекорд

Гра запам'ятовує найбільшу кількість набраних очок під час поточного запуску програми.

Рекорд показується у верхній частині гри:

```text
🏆 Record: 25
```
